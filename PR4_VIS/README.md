Консольное приложение на языке C#
Обрабатывает анкеты данных из текстового файла

Program.cs - Точка входа и управления процессом обработки данных
DataBase.cs - Классы хранения данных анкет и информации об ошибках
Validator.cs - Проверка валидации ФИО, почты, телефона, группы
Report.cs - ВЫвод таблицы статистики и списка ошибок
Storage.cs - Чтение входного файла и сохранение результата
